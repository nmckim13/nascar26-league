# Travis Pastrana #42

The default #42 badge follows Travis Pastrana’s 2026 BRUNT Workwear Craftsman Truck Series door number: white italic numerals, orange trim and a black shadow.

Reference: https://diecastcharv.com/2026-travis-pastrana-truck-number-cards/
