# BARL truck artwork

Craftsman Truck Series body-style illustrations for the driver-card artwork. The original stock-car assets remain under `assets/cars/` for reference and possible restoration.

Each image uses a consistent front-left three-quarter camera, landscape canvas, and transparent background. Names and profile links remain live HTML.

The 14 active roster numbers are 5, 6, 7, 9, 17, 19, 20, 23, 24, 42, 54, 60, 88 and 97. Chevrolet schemes use Silverado bodies, Ford schemes use F-150 bodies, and Toyota schemes use Tundra bodies. The existing BARL colors and sponsors are adapted onto racing pickups; these are AI illustrations, not official game exports or claims of real Truck Series entries.

The #88 retains its Diet Mountain Dew / National Guard throwback. The #42 uses the Pastrana-style BRUNT livery and the reference-derived number badge. #23 receives a Hardee's truck rather than a vehicle-art placeholder. Generation prompts and source paths are recorded in `prompts.json`. Web exports use transparent WebP at quality 86, 1536×1024.

`data/car-art.js` supplies explicit vehicle image paths and truck model names. `scripts/profile-car-card.js` keeps driver names, badges and career links separate from the generated art. Profile cards use a taller 1.8:1 stage with centered framing to show the full truck silhouette. The homepage winner illustration uses the new #88 truck.
